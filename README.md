# Chang Hwan Kim — Academic Personal Website

Personal academic website built with plain HTML/CSS, hosted on GitHub Pages.

**Live site:** https://chang-hwan-kim1.github.io/

## How to update

- **Profile info / links:** Edit `index.html`
- **Styles:** Edit `assets/css/style.css`
- **Profile photo:** Replace `assets/images/profile.jpg`

## Local preview

Open `index.html` directly in your browser — no build step needed.
